# 지붕 덮개 (Roof Reveal) 가이드

시설 위에 **지붕을 덮어 두었다가, 커서를 대거나 클릭하면 지붕이 날아가며 내부가 드러나는** 연출(인형의 집).
**그림이 없어도 게임은 그대로 동작**하며, 아래 규칙대로 PNG를 넣으면 자동 적용됩니다.

## 파일 네이밍

```
assets/images/buildings/<zone>_idle.png   ← 내부(지붕 없는) 모습. 이미 존재.
assets/images/buildings/<zone>_roof.png   ← 지붕 덮개. 새로 그려서 넣으면 됨.
```

지금 적용 대상: **barracks(숙소)** → `barracks_roof.png`
(다른 시설도 가능 — `engine/village.js`의 `ROOF_ZONES`에 `<zone>: true` 추가.)

## 규격 (중요)

- **`<zone>_idle.png` 와 `<zone>_roof.png` 는 같은 캔버스 크기**여야 자동 정렬됩니다.
  - 현재 barracks = **1379 × 1192** (지붕 헤드룸 위해 세로를 933→1192로 키움, **아래쪽 기준** 유지: 건물은 캔버스 맨 아래, 위쪽 259px는 투명).
  - roof도 1379×1192, 지붕은 위쪽(대략 y 0~726)에 그리고 나머지 투명.
- **캔버스를 키웠으면 `engine/village.js`의 해당 ZONE에 `rh`(렌더 높이 %)를 보정**해야 건물이 작아지지 않습니다.
  - 공식: `rh = box[3] × (캔버스높이 / 건물내용높이)`. barracks: `38.6 × 1192/933 ≈ 49.3`.
  - idle·roof 모두 이 `rh`로 렌더되어 화면에서 같은 크기·위치로 겹칩니다.
- 지붕이 날아갈 때 위로 떠오르며 살짝 기우니, 지붕 윗변 여유 픽셀이 있으면 잘리지 않습니다.

## ⚠ 내보내기 주의 — 반드시 "진짜 PNG"로

포토샵에서 저장할 때 **PNG 형식으로 정확히 내보내야** 합니다. (`barracks_idle.png`가 한 번 *Photoshop 포맷*인데 확장자만 .png로 저장돼 브라우저가 디코드 실패 → 건물이 통째로 안 보였습니다.)
- 권장: **File ▸ Export ▸ Export As… → PNG** (또는 "Save a Copy → PNG"). "Save As"로 PSD 옵션이 섞이지 않게.
- 확인법(터미널): `file 그림.png` → `PNG image data …` 라고 나와야 정상. `Adobe Photoshop Image` 라고 나오면 잘못된 것.
- 8비트 RGBA, 투명 배경. (16비트/CMYK 금지)

## 동작

- 평소: 지붕이 덮여 있음.
- **커서를 올리면**: 지붕이 위로 날아가며 사라짐(0.5초) → 내부(`_idle.png`)와 그 안의 인물이 드러남. 커서를 떼면 다시 덮임.
- **클릭하면**: 시설 정보창이 열리는 동안 지붕이 계속 열려 있음. 정보창을 닫으면 다시 덮임.

## 팁

- `barracks_idle.png`를 배경 레퍼런스로 깔고, 그 위에 지붕(기와/천막/슬레이트 등)을 덮어 그린 뒤 idle 레이어를 숨기고 지붕만 PNG로 저장하면 위치가 정확히 맞습니다.

# 폐허의 불빛 — Light of Ruins (웹 구현)

대학원 게임 디자인 과제 『폐허의 불빛 v1.2』(김소연 · 홍익대학교 대학원)의 30일 풀 사이클 웹 구현체.
좀비 생존 마을을 매일 돌보며, 한 번의 결정이 마을의 도덕적 좌표계가 되는 선택형 서사 게임.

## 실행 방법

### 옵션 1 — 더블클릭 (가장 간단)
`index.html`을 더블클릭. 모던 브라우저에서 그대로 열림. 단, 일부 브라우저에서 `file://` 보안 제약으로 글꼴·이미지 로드가 제한될 수 있음.

### 옵션 2 — 로컬 정적 서버 (권장)
이 폴더에서:
```
python3 -m http.server 8765
```
브라우저에서 `http://localhost:8765` 접속.

### 옵션 3 — 깃허브 페이지 배포
이 폴더 전체를 깃허브 레포에 올리고 Pages 활성화. 별도 빌드 없이 즉시 배포.

> 코드를 갱신했는데 옛 화면이 보이면 **강력 새로고침**(⌘/Ctrl+Shift+R) 또는 시크릿 창으로 열기.

## 어떻게 플레이하나

1. 타이틀에서 **새 게임**. 매 아침 화면이 잠깐 암전되며 **`Day N` + 식량·사기·소음**이 뜬다(클릭하면 넘어감).
2. **마을 전경**이 메인 플레이 화면. 마우스로 둘러보고(휠로 줌 인/아웃, 끝까지 패닝), 인물·시설을 클릭해 상태를 본다.
3. **오늘의 살림** — 매일 한 번씩 시설을 돌본다:
   - 🪣 **물 뜨기**(빗물받이) · 🌱 **수확**(밭, 물이 있어야 함) · 🍳 **요리/저장 가공**(부엌)
   - 상단 `오늘의 살림 N/3`과 시설 위 ●/✓ 표시로 남은 일을 확인.
4. **오늘의 결정** — 하단 대화창에서 A/B/C 중 선택. 선택의 결과는 **컷씬 + 자원 변화**로 보여준다.
5. 결정이 끝나면 밤이 지나고(소음이 높으면 습격·부상), 다음 아침으로. 30일 뒤 **엔딩**.

## 게임 구조

- **30일 한 사이클** + **엔딩 8종** — 생존 5(빛의 마을 / 잊혀진 마을 / 흔들리는 마을 / 안전지대 도달 / 30일 생존) + 게임오버 3(꺼진 등불 / 흩어진 사람들 / 말 없는 마을). 각 엔딩 전용 일러스트.
- **자유 분기 선택** A/B/C
- **하이브리드 시나리오**: 손글씨 시나리오(D1~7 봄편, D14~16 가을편, D24~26 겨울편) + 마을 상태 기반 자동 생성 시나리오

## 연출·UX

- **마을 전경** — 풀캔버스 배경 3겹 패럴럭스, 휠 줌(전체 보기↔접근), 끝까지 패닝
- **하루 전환** — 매 아침 암전 → `Day N` + 핵심 3축 표시 → 클릭하면 밝아짐
- **컷씬** — 모든 선택·스몰윈·부상에 일러스트 + 자원 변화 칩(스몰윈은 1:1 카드, 보상 톤 금색 연출)
- **대사 가독성** — 문장(마침표/물음표/느낌표)마다 줄바꿈, 화자별 캐릭터색, 인물 포트레이트, '기록'은 노트(괘선지) 느낌
- **사운드** — 우하단 🔊 토글로 배경음악·환경음(빗소리·모닥불)·버튼음 일괄 on/off (설정 기억)

## 에셋

이미지·음원을 **정해진 경로·파일명**으로 올리면 자동으로 끼워지고, **없으면 안전하게 폴백**(깨지지 않음). 전체 슬롯 명세는 [`ASSETS.md`](ASSETS.md), 프롬프트는 [`ART_PROMPTS.md`](ART_PROMPTS.md), 캐릭터 스프라이트 규격은 [`SPRITES.md`](SPRITES.md).

현재 상태:
- ✅ 배경 · 인물(풀캔버스) · 포트레이트 · 건물 · 스몰윈 카드 · **엔딩 일러스트 8장** 적용 완료
- 🟡 (선택) 대화창 반신 그림 `assets/images/busts/{char}.png` — 없으면 포트레이트로 폴백
- 🟡 (선택) 배경음악 `assets/audio/bgm.mp3` — 없으면 환경음·버튼음만

## 재미 설계 — 「게임서사의 층위」 프레임

Kahneman 이중처리 모델 기반의 재미 층위(시스템1 반응 / 시스템2 사고 / 두 시스템의 충돌)를 메카닉으로 구현.

**시스템1 — 반응의 층위**
- 선택지마다 **예상 소음 → 오늘 밤 습격 확률 칩**: '사기를 올리면 위험이 커진다'는 모순을 누르기 전에 감지
- 음향 스코프 실시간 파형 + 소음 동심원, 습격 확률 60%+ 시 화면 가장자리 붉은 비네트, 습격·부상 컷씬

**시스템2 — 사고의 층위**
- 아침마다 **간밤 판정 인과 노트**: "소음 24(주의) → 습격 25% → 비껴갔다"로 규칙을 추론·학습
- 외출/배급/살림의 트레이드오프를 명시(보상·위험·잔류 전망)해 의식적 판단 유도
- 전례 시간 반감·상승 나선 연속 일수 — 장기 전략의 재료

**시스템1×2 충돌 — This War of Mine 계보**
- 간병 포기는 메카닉상 가장 '싼' 선택이지만 부정 전례를 생성 — 조작이 쉬울수록 윤리적 불편이 커지는 구조
- 전례 생성 다음 아침, 감수성 표에 따라 **갈리는 인물 반응 2개** 자동 표시 — 같은 사건, 다른 기울기

**창발적 서사 (Dwarf Fortress·RimWorld 계보)**
- 스몰윈 19종 × 발동 조건 × 습격/탐색 부상 변주가 플레이마다 다른 '그 마을만의 이야기'를 생성
- 같은 '생존' 엔딩도 전례 누적 프로파일에 따라 빛의/흔들리는/잊혀진 마을로 분기

## 기술 스택

- HTML5 + CSS3 + 순수 JavaScript (ES2017+), **빌드 도구·의존성 없음**
- 모든 파일 클래식 스크립트로 로드 (단일 `LR` 글로벌 네임스페이스)
- Web Audio API로 환경음·버튼음 합성, localStorage 자동 저장
- 한국어 폰트: Noto Sans KR · 픽셀 폰트: Galmuri

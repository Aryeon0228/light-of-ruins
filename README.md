# 폐허의 불빛 — Light of Ruins (웹 구현)

대학원 게임 디자인 과제 『폐허의 불빛 v1.2』(김소연 · 홍익대학교 대학원)의 30일 풀 사이클 웹 구현체.

## 실행 방법

### 옵션 1 — 더블클릭 (가장 간단)
`index.html`을 더블클릭. 모던 브라우저에서 그대로 열림. 단, 일부 브라우저에서 `file://` 보안 제약으로 글꼴 로드 등이 제한될 수 있음.

### 옵션 2 — 로컬 정적 서버 (권장)
이 폴더에서:
```
python3 -m http.server 8765
```
브라우저에서 `http://localhost:8765` 접속.

### 옵션 3 — 깃허브 페이지 배포
이 폴더 전체를 깃허브 레포에 올리고 Pages 활성화. 별도 빌드 없이 즉시 배포.

## 재미 설계 — 「게임서사의 층위」 프레임 반영

수업에서 다룬 Kahneman 이중처리 모델 기반의 재미 층위(시스템1 반응 / 시스템2 사고 / 두 시스템의 충돌)를 메카닉으로 구현한다.

**시스템1 — 반응의 층위 (즉각 피드백·위험 감지)**
- 선택지마다 **예상 소음 → 오늘 밤 습격 확률 칩** 표시: '사기를 올리면 위험이 커진다'는 핵심 모순을 누르기 전에 몸으로 감지
- 음향 스코프 실시간 파형 + 소음 동심원, 습격 확률 60%+ 시 **화면 가장자리 붉은 비네트** 고동
- 습격·부상 컷씬 진입 시 **화면 흔들림**, 자원 변동 즉시 플래시

**시스템2 — 사고의 층위 (추론·전략·도덕 판단)**
- 아침마다 **간밤 판정 인과 노트**: "소음 24 (주의) → 습격 확률 25% → 비껴갔다" — 규칙을 숫자로 추론·학습 (Koster: 재미는 학습이다)
- 외출 컨펌 패널: 보상(식량 며칠치)·위험(%·피해 범위)·잔류 전망을 명시해 **의식적 트레이드오프 판단** 유도
- 전례 시간 반감 곡선·상승 나선 연속 일수 — 장기 전략 판단의 재료

**시스템1×2 충돌 — This War of Mine 계보 (수업 사례)**
- 간병 포기는 메카닉상 가장 '싼' 선택(자원 0 소비)이지만 부정 전례 P-를 생성 — **조작상 쉬울수록 윤리적 불편이 커지는** 구조
- 전례 생성 다음 날 아침, **감수성 표에 따라 갈리는 인물 반응 2개** 자동 표시(가장 민감한 자 vs 가장 둔감한 자) — 같은 사건, 다른 기울기

**창발적 서사 (수업: Dwarf Fortress·RimWorld 사례)**
- 스몰윈 17종 × 발동 조건 × 습격/탐색 부상 변주가 플레이마다 다른 '그 마을만의 이야기'를 생성
- 같은 '생존' 엔딩도 전례 누적 프로파일에 따라 빛의/흔들리는/잊혀진 마을로 분기
